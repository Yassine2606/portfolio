# Vision

Build a portfolio that feels less like a personal website and more like an interactive software product.

The objective is not simply to display projects, but to convince visitors that the owner engineers modern AI-powered software with production-quality thinking.

The portfolio should communicate:

- Intelligence
- Engineering excellence
- Attention to detail
- Technical depth
- Product thinking
- Premium user experience

It should be memorable enough that recruiters, founders and engineers remember it after closing the tab.

# Questions to Answer During Brainstorming

1. What should visitors remember after leaving?

2. Which section should create the "wow" moment?

3. Which project deserves the most attention?

4. Should the website tell a story or behave like an application?

5. Which interactions genuinely communicate engineering skill?

6. Which animations are meaningful instead of decorative?

7. How can AI be demonstrated rather than simply mentioned?

8. Which sections can become interactive experiences?

9. How can technical depth remain understandable to non-engineers?

10. Which parts make recruiters stay longer than two minutes?

---

# Success Criteria

A recruiter should be able to understand the following within 30 seconds:

✔ What kind of engineer this is

✔ What problems they solve

✔ Their technical depth

✔ Their strongest projects

✔ Their engineering philosophy

✔ How to contact them

Within 5 minutes, visitors should leave convinced that this is someone capable of building production-quality AI software with strong product and engineering instincts.
