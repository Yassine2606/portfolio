# Case studies

One file per project: `<slug>.mdx`.

- The slug must match the filename and the `slug` field in frontmatter.
- Frontmatter is validated at build by `src/lib/content/schema.ts`; a bad file fails the build.
- Every case study needs at least one evidence entry and no more than four metrics.
- Use the skeleton in `docs/11-content-templates.md`.
- Never add a claim that is not in `docs/evidence-ledger.md`.

Files land here in Phase 4, after the evidence sprint.
